EZEE VISION CHAMPUA — Homepage Prototype
========================================

FILES
- index.html: Complete responsive single-page coaching portfolio. CSS, animations and JavaScript are embedded in one file.

HOW TO PREVIEW ON ANDROID
1. Download and extract the ZIP.
2. Open index.html in Chrome or your preferred browser.
3. For editing, open index.html in Acode, Spck Editor, or another HTML editor.

HOW TO DEPLOY TO VERCEL
1. Create a GitHub repository (e.g. ezee-vision-portfolio).
2. Upload index.html to the repository root.
3. Import that repository in Vercel and deploy. No build command is required for this static prototype.

WHAT IS INCLUDED
- Responsive mobile-first layout
- Sticky responsive navigation and mobile menu
- Scroll reveal animations, animated marquee, floating stickers, CSS 3D card styling and pointer tilt on desktop
- Course cards, teaching methodology, coaching journey timeline, founder profile, learning gallery, contact section and footer
- WhatsApp enquiry form (opens WhatsApp with a pre-filled message; it does not store submitted data)
- Reduced-motion accessibility support

BEFORE PUBLISHING
- Verify the contact phone numbers and address.
